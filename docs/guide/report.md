# 实验报告与提交规范

## 一、报告要求

实验报告应参考《武汉大学计算机学院课程设计报告书写规范》（见下方附件），按规范中的模板和格式要求撰写。一组提交 1 份实验报告即可。

:::info[报告书写规范]
点击下载：[武汉大学计算机学院课程设计报告书写规范.doc](pathname:///word/武汉大学计算机学院课程设计报告书写规范.doc)
:::

报告中应至少包含以下内容：

- **实验内容**：本次实验的具体任务和实现目标
- **实验目的**：本次实验要达成的能力目标
- **实验原理**：涉及的编译理论，如正则表达式、有限自动机、LR 分析、SSA 形式、数据流分析等
- **设计思路**：整体架构设计、模块划分、数据结构选择
- **关键算法与流程描述**：核心算法的伪代码或流程图
- **测试结果**：测试用例与运行结果，附运行截图或输出
- **分工**：小组各成员负责的模块以及贡献比例，参考格式如下：

  | 姓名 | 学号 | 负责模块 | 贡献比例 |
  | --- | --- | --- | --- |
  | 张三 | 20240001 | 词法分析器、语法分析器 | 35% |
  | 李四 | 20240002 | IR 生成、代码优化 | 35% |
  | 王五 | 20240003 | 目标代码生成、寄存器分配 | 30% |
  | 赵六 | 20240004 | 无 | 0% |
- **遇到的问题和解决思路**：遇到的典型问题与解决方案
- **心得体会**：实验总结与思考

报告中还应记录构建命令、运行命令，助教可能会构建运行。



## 二、提交方式

实验代码提交到仓库后由评测平台自动拉取与编译； 
实验报告由后续统一提供的提交入口单独提交。

提交代码时可参考以下步骤操作：

```bash
# 1. 切到本次实验的分支
git checkout -b part1-lexer

# 2. 提交本次实验的代码
git add .
git commit -m "part1: 完成词法分析器"

# 3. 推送到远端并发起 PR
git push -u origin part1-lexer
```

在远程仓库上发起 Pull Request，标题格式为 `[Part1] 学号 姓名`。
