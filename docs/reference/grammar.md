# ToyC 词法与文法约定

全部实验共用同一门语言 ToyC。本节定义各实验使用的文法、词法规则与语义约束。

## 一、上下文无关文法

下面使用 EBNF 记号：`[ ... ]` 表示可选，`*` 表示重复零次或多次，`+` 表示重复一次或多次，`|` 表示选择；单引号中的内容是终结符。

<ToyCGrammar />

库函数调用不需要单独出现在文法中。`getint` 和 `putint` 仍按普通 `ID` 解析，
由语义分析预置函数符号，由目标代码生成阶段生成外部调用。

## 二、终结符特征

### 关键字

```text
int  void  const  if  else  while  break  continue  return
```

### 标识符

终结符 `ID` 的正则表达式为：

```text
[_A-Za-z][_A-Za-z0-9]*
```

### 整数

终结符 `NUMBER` 识别不带正负号的十进制整数常量：

```text
(0|[1-9][0-9]*)
```

负号统一识别为 `-` 运算符，由 `UnaryExpr` 处理。因此 `-3` 的 Token 序列是 `'-'`、`IntConst(3)`，各实验不再为负数另设词法规则。

### 运算符与界符

```text
+  -  *  /  %  =  ==  !=  <  >  <=  >=  &&  ||  !
(  )  {  }  ;  ,
```

### 空白和注释

空白字符和注释均被忽略。空白包括空格、制表符和换行符；单行注释以 `//` 开始，
到最近换行符前结束；多行注释以 `/*` 开始，以最近的 `*/` 结束。

## 三、语义约束

### 程序结构

程序必须包含一个名为 `main`、参数列表为空、返回类型为 `int` 的函数作为入口点。

### 函数

函数只能声明在全局作用域中且名称唯一，不能声明在函数体内。函数支持若干 `int`
类型参数，返回值可以是 `int` 或 `void`。函数不能作为值存储、传递或运算；函数调用
必须写在被调函数声明之后，但支持函数内部调用自身。

`int` 函数必须在每条可能执行路径上返回一个 `int` 值；`void` 函数可以没有 return，
但如果包含 return，则不能有返回值。

### 变量声明

每条声明只定义一个 32 位有符号整数变量，初始化表达式可以省略：

```c
int a;
int x = 0;
int b = 1;
int d = x + b;
```

`int a = 1, b = 2;` 不属于 ToyC 文法。变量只能声明在函数内，每个变量名在同一作用域内只能声明一次。省略初始化的局部变量没有默认值，必须在读取前赋值；不能依赖未初始化读取的结果。

局部常量使用 `const int` 声明，同样每条只声明一个名称且必须初始化，声明后不能再次赋值：

```c
const int limit = 10;
const int step = 2;
```

`const` 仅用于函数内的局部声明，不支持全局常量。初始化表达式可以调用函数或引用当前可见变量，因此局部 `const` 的值不一定在编译期已知；只有初始表达式已被证明为常量时才能直接折叠。

变量的使用必须发生在声明之后。语句块创建新的作用域，函数形参与函数体最外层局部变量共享该层作用域；内层语句块可以屏蔽外层变量名。

### 语句与控制流

空语句、表达式语句、赋值、声明、if-else、while、break、continue 和 return 的语义遵循 C 语言习惯。`else` 与最近一个尚未匹配 `else` 的 `if` 配对。没有返回值的函数调用不能作为 if/while 条件或赋值右值；`break` 和 `continue` 只能出现在循环中。

### 表达式

逻辑与和逻辑或必须短路求值；非零值为真、零值为假；除数不能为零。`int` 的有效运算须遵守 32 位有符号整数语义，不能把有符号溢出或 `INT_MIN / -1` 当成正常算术结果。

## 四、运算符优先级与结合性

| 优先级 | 运算符 | 结合性 |
| --- | --- | --- |
| 1（最高） | 函数调用、括号 | 左 |
| 2 | `!` `+` `-`（一元） | 右 |
| 3 | `*` `/` `%` | 左 |
| 4 | `+` `-` | 左 |
| 5 | `<` `>` `<=` `>=` `==` `!=` | 左 |
| 6 | `&&` | 左 |
| 7（最低） | `\|\|` | 左 |

关系与相等运算符都由 `RelExpr` 处理，处于同一优先级层；表达式分析和 AST 构造以这份文法为准。

## 五、输出格式

各实验的输出格式由对应的实验指导书规定。这里先汇总两种最常用的格式，完整规范（含样例程序的完整输入输出）见各实验页面。

### Token 流（第一部分）

每行一个 Token，写到标准输出流，格式为 `<序号>:<类型>:<内容>`：

```text
0:'int':"int"
1:Ident:"main"
2:'(':"("
```

- 序号从 `0` 开始，按出现顺序递增；
- 关键字、运算符、界符写成该符号本身并加单引号（`'int'`、`'<='`、`'('`）；标识符写作 `Ident`，十进制整数常量写作 `IntConst`；
- 符号和标识符的内容是源程序中的原始文本，用双引号括起；`IntConst` 的内容直接写十进制数值，不加引号；
- 空白和注释不产生 Token，所以序号是连续的。

完整样例见[第一部分 · 词法分析](../labs/part1-lexer)的“输入输出规范与统一样例”。

### 语法检查（第二部分）

源代码没有语法错误时，只输出一行 `accept`；否则先输出一行 `reject`，再按出现顺序逐行输出出错位置：

```text
<行号>[ 空格 <报错信息>]
```

行号从 `1` 开始，报错信息可省略。完整样例见[第二部分 · 语法分析](../labs/part2-parser)。

### 目标汇编（第四部分）

把所有测试用例（保证无词法、语法、语义错误）直接翻译成 RISC-V64GC 汇编，写到标准输出流；
具体指令序列和标号命名由实现自行决定。完整样例见[第四部分 · 目标代码生成](../labs/part4-codegen)。

### 三地址码（第三部分可选）

如果第三部分选择自定义三地址码而不是 LLVM IR，可以用四元式表示：

```text
(op, arg1, arg2, result)
```

例如 `a = b + c * d`：

```text
(*, c, d, t0)
(+, b, t0, t1)
(=, t1, _, a)
```
